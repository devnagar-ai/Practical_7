# Multi-Utility Toolkit

A menu-driven Python console project for date and time, math, random data, UUID, and text-file tasks. It demonstrates Python's standard modules, a small custom package, input validation, `dir()` module exploration, and the `if __name__ == "__main__"` entry point.

## Features

- **Date and time:** current date/time, date differences, formatting, stopwatch, and countdown.
- **Math:** factorial, compound interest, trigonometry, shape areas, and unit conversions.
- **Random tools:** integers, number lists, passwords, OTPs, and sampling.
- **UUIDs:** generate one or more UUID4 identifiers.
- **File tools:** create, read, replace, or append to text files.
- **Module explorer:** list attributes of selected Python standard-library modules.

## Requirements

Python 3.8 or newer. No third-party packages are required.

## Run

```bash
python main.py
```
